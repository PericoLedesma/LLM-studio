## 🧠 AI Libraries & Apps Overview

This table summarizes the **popular libraries and applications** used for working with local and hosted LLMs (Large Language Models).

---

### 🔧 Libraries

These are frameworks and tools commonly used to **build, fine-tune, convert, or serve** LLMs:

| Logo | Library            | Description |
|------|--------------------|-------------|
| 🔥   | **PyTorch**         | A leading deep learning library used to train and run LLMs. |
| 🟧   | **TensorFlow**      | Google’s deep learning framework, often used in production. |
| 🌈   | **JAX**             | Optimized for high-performance ML, popular in research. |
| 🤗   | **Transformers**    | Hugging Face library for pre-trained transformer models. |
| 🎨   | **Diffusers**       | Tools for running diffusion models like Stable Diffusion. |
| 🛡️   | **Safetensors**     | A fast and secure format for saving model weights. |
| 🧠   | **ONNX**            | Open standard for inter-framework model conversion. |
| 📄   | **GGUF**            | Lightweight format for quantized models in `llama.cpp`. |
| 🧩   | **Transformers.js** | Run models in JavaScript in browsers or Node.js. |
| 💾   | **MLX**             | Apple’s ML framework optimized for Apple Silicon. |
| 🟥   | **Keras**           | High-level neural network API running on TensorFlow. |


---

### 🚀 Apps

These are **inference apps and backends** that let you run or serve LLMs:

| Logo | App         | Description |
|------|-------------|-------------|
| ⚡   | **vLLM**      | Fast inference engine using PagedAttention (GPU optimized). |
| 💬   | **TGI**       | Hugging Face’s production server for LLM inference. |
| 🦙   | **llama.cpp** | Lightweight LLaMA inference on CPU using GGUF format. |
| 🍎   | **MLX LM**    | Run LLMs efficiently on Apple Silicon via MLX. |
| 🖥️   | **LM Studio** | GUI desktop app to run models locally. |
| 🌍   | **Ollama**    | Local inference app with REST API and easy setup. |
| ☀️   | **Jan**       | Private, open-source assistant that runs locally. |


---

### 📌 Summary

- **Libraries** = Tools for developing, loading, quantizing, or serving models.
- **Apps** = User-friendly environments or servers for running models interactively.
- Covers both **lightweight CPU-based** setups (e.g., `llama.cpp`) and **GPU-powered** setups (e.g., `vLLM`, `TGI`).
