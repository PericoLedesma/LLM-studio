# 🧠 Lang Ecosystem Schema

### 📦 Core Components

| Component                                | Description                                                                             |
|------------------------------------------|-----------------------------------------------------------------------------------------|
| **LangChain Core**                       | The foundational library for building LLM-powered applications.                         |
| **LangGraph**                            | A library for building stateful, multi-step workflows using a graph-based architecture. |
| **LangChain Expression Language (LCEL)** | A declarative way to compose chains and agents.                                         |
| **Agents**                               | Autonomous entities that leverage tools to accomplish tasks.                            |
| **Chains**                               | Sequences of calls (to LLMs, tools, etc.) that form workflows.                          |
| **Tools**                                | External functions or APIs that agents can utilize (e.g., search, calculator).          |
| **Memory**                               | Mechanisms for storing and retrieving context across interactions.                      |
| **Callbacks**                            | Hooks for logging, tracing, and monitoring chain execution.                             |

### 🔌 Integrations

| Category             | Examples                                             |
|----------------------|------------------------------------------------------|
| **LLM Providers**    | OpenAI, Anthropic, Cohere, Hugging Face, Google PaLM |
| **Embedding Models** | OpenAI, Cohere, Hugging Face, TensorFlow             |
| **Vector Stores**    | Pinecone, Weaviate, FAISS, Chroma, Milvus            |
| **Databases**        | MongoDB, PostgreSQL, Redis, Supabase                 |
| **Document Loaders** | PDF, HTML, CSV, Notion, Slack, Google Docs           |
| **Toolkits**         | SerpAPI, Wolfram Alpha, Zapier, Browser, Calculator  |

### 🛠️ Development Tools

- **LangSmith**: Observability and debugging platform for LangChain applications.  
- **LangServe**: Tool for deploying LangChain chains as REST APIs.  
- **LangChainHub**: Repository of community-contributed chains and agents.  

### 🚀 Deployment Options

- **Local**: Python, JavaScript  
- **Serverless**: e.g., Vercel, AWS Lambda  
- **Containerized**: Docker  
- **API-based**: LangServe, FastAPI
